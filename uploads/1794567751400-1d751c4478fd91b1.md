# Краткий план и вопросы для Славы
Дата: 2026-11-13
Товар: фитонцидная вытяжка пихты, карточка 1015

## План действий
1. Собрать все данные о товаре в один текстовый файл.
2. Сделать запрос нейросети, чтобы она написала описание по образцу из задания.
3. Нарисовать сами заднюю этикетку бутылки и коробку, чтобы текст был читаемый (вместо генерации картинок с текстом).
4. Сделать пять картинок: природа; белый фон спереди; белый фон сзади; продукт с людьми; продукт в коробке.
5. Собрать готовую карточку и сохранить картинки размером 600 на 600.

1. Всего картинок четыре или пять?

3. Размер 600 на 600 делать для всех картинок?
4. Откуда взять точные проценты состава?
5. Можно ли убрать из текста спорные медицинские обещания?
6. Подтверждаем, что картинки делаем генерацией и своими съёмками, а не берём из чужих источников?
