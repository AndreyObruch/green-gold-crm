Green Gold CRM

Правила пользования CRM «Green Gold», v3

  1. Работай только под своим аккаунтом.
  2. Жизненный цикл задачи: Новая → В работе → Готово; готовое не удаляется, архивирует админ.
  3. Файлы: до 3 за одну загрузку (при создании задачи), в чате → по 1 файлу на сообщение; каждый файл до 10 МБ; общее число файлов на задачу не ограничено.
  4. Обсуждение задачи → в чате задачи, не во внешних мессенджерах.
  5. Статус и комментарий обновляй в день изменения.
  6. Ошибка → сообщи админу в чате задачи с указанием ID задачи.

Роли и права

  • admin: создание, правка, удаление, архив, восстановление задач и все файлы.
  • executor: только свои задачи, смена статуса, свои файлы.

Файлы и форматы

  • pdf, png, jpg, jpeg, docx, xlsx, csv, txt.
  • Вложение при создании задачи → до 3 файлов сразу; в чате → кнопка «Файл» (1 файл на сообщение); скачивание → по клику.

Связь (чат задачи)

  • Открой карточку (клик по заголовку) → раздел «Чат задачи» → пиши сообщения и прикрепляй файлы.
  • Задержка появления ответа собеседника в чате ~4 секунды (пока открыта карточка задачи).
  • Исполнитель и создатель видны в мете карточки.

Гигиена и безопасность

  • Не передавай пароль; на общем ПК нажимай «Выйти».
  • Не загружай личное, не относящееся к задаче.
