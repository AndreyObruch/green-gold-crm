# Green Gold CRM

Единое краткое описание системы для команды.

---

## 1. Что это

Green Gold CRM — локальная система учёта задач, файлов и рабочего общения по задачам.

Сервер запускается на одном компьютере и работает внутри локальной сети организации.

Основные данные хранятся локально:

- задачи, пользователи, сообщения и журнал действий — в базе `crm.db`;
- загруженные файлы — в папке `uploads`.

Система не публикуется в интернете и доступна только устройствам, которые находятся в той же локальной сети.

---

## 2. Как открыть систему

### На компьютере, где запущен сервер

Открой в браузере:

```text
http://localhost:3000
```

`localhost` означает «этот же компьютер».

То есть если сервер запущен на твоём ПК, ты открываешь систему у себя через `localhost`.

### На компьютере коллеги в локальной сети

Открой в браузере:

```text
http://172.25.46.103:3000
```

Этот адрес доступен только устройствам в той же локальной сети.

Если IP-адрес сервера изменился, уточни актуальный адрес у администратора.

---

## 3. Что такое порт 3000

Порт `3000` — это сетевой порт приложения Green Gold CRM.

Простыми словами:

- компьютер имеет адрес в сети;
- внутри компьютера может работать много программ;
- каждая программа использует свой порт;
- Green Gold CRM использует порт `3000`.

Пример адреса:

```text
http://172.25.46.103:3000
       |              |
       |              +-- порт приложения CRM
       +----------------- адрес компьютера в локальной сети
```

Важно:

- `localhost:3000` — это доступ к серверу с того же компьютера;
- `172.25.46.103:3000` — это доступ к тому же серверу из локальной сети;
- порт `3000` — это не шлюз и не интернет-адрес, а номер «двери» внутри компьютера.

Если сервер остановлен, страница по этому адресу не откроется.

---

## 4. Как запустить сервер

Запуск выполняет администратор на компьютере, где установлена система.

Открой PowerShell в папке проекта и выполни:

```powershell
cd "C:\Users\user\Projects\Green Gold\green-gold-crm"
node server.js
```

Успешный запуск выглядит примерно так:

```text
Server on http://localhost:3000
Database initialized
...
```

Пока окно с `node server.js` открыто и процесс работает, система доступна.

Если процесс остановить, CRM станет недоступна для всех пользователей.

---

## 5. Вход в систему

Вход выполняется только под личной учётной записью.

Нельзя:

- передавать логин и пароль коллегам;
- работать под чужим аккаунтом;
- использовать общий пароль;
- сохранять пароль в общих файлах или чатах.

На общем компьютере после работы нужно нажать кнопку:

```text
Выйти
```

Это завершает текущую сессию и защищает данные от случайного доступа.

## 6. Роли пользователей

### Admin

Администратор может:

- создавать задачи;
- назначать одного или нескольких исполнителей;
- менять название, описание, статус и состав исполнителей;
- удалять задачи в архив;
- восстанавливать задачи из архива;
- смотреть все задачи, файлы и чаты;
- управлять пользователями, если это предусмотрено настройками системы.

### Executor

Исполнитель может:

- видеть только те задачи, где он назначен;
- менять статус своей задачи;
- участвовать в чате задачи;
- прикреплять файлы к своим задачам;
- скачивать файлы, доступные по его задаче.

Исполнитель не видит чужие задачи, если он не назначен на них.

---

## 7. Жизненный цикл задачи

Стандартный путь задачи:

```text
Новая -> В работе -> Готово
```

Правила:

- статус нужно обновлять в день изменения;
- если задача взята в работу, статус меняется на `В работе`;
- если результат готов, статус меняется на `Готово`;
- готовую задачу не удаляет исполнитель;
- удалением и архивом управляет администратор.

---

## 8. Файлы

Разрешённые форматы:

```text
pdf, png, jpg, jpeg, docx, xlsx, csv, txt, md
```

Лимиты:

- один файл — не более 10 МБ;
- при создании задачи можно загрузить до 3 файлов за один раз;
- в одно сообщение чата можно прикрепить до 3 файлов;
- общее количество файлов на задачу не ограничено, если файлы проходят по формату и размеру.

Файлы доступны:

- администраторам;
- исполнителям, назначенным на эту задачу.

Загружать личные файлы, документы не по рабочей задаче или материалы с конфиденциальными данными без необходимости нельзя.

---

## 9. Чат задачи

Обсуждение задачи ведётся в чате задачи, а не во внешних мессенджерах.

В чате участвуют:

- администраторы;
- все исполнители, назначенные на задачу.

В чате можно:

- писать текстовые сообщения;
- прикреплять файлы;
- обсуждать статус, результаты и проблемы по задаче.

Сообщения и вложения сохраняются в базе данных.

Задержка появления нового сообщения в открытом чате — примерно 4 секунды, пока карточка задачи открыта в браузере.

Это не гарантирует мгновенную доставку, как в полноценном мессенджере, но достаточно для рабочего общения внутри CRM.

## 10. Если система не открывается

Проверь по порядку.

### 1. Сервер запущен

На серверном компьютере должен работать процесс:

```powershell
node server.js
```

В консоли должна быть строка:

```text
Server on http://localhost:3000
```

### 2. Адрес введён правильно

Для своего компьютера:

```text
http://localhost:3000
```

Для коллег в локальной сети:

```text
http://172.25.46.103:3000
```

### 3. Ты в той же локальной сети

Если ты подключён к другому Wi-Fi, другому сегменту сети или к интернету без доступа к внутренней сети, адрес `172.25.46.103:3000` может быть недоступен.

### 4. Порт разрешён в брандмауэре

На серверном компьютере должен быть разрешён входящий трафик на TCP-порт `3000` для локальной сети.

### 5. IP-адрес сервера мог измениться

Если компьютер перезагружался или сеть менялась, адрес мог стать другим. Уточни актуальный IP у администратора.

### 6. Браузер показал старую версию страницы

Нажми:

```text
Ctrl + Shift + R
```

Это принудительно обновит страницу без кэша.

---

## 11. Главное

Green Gold CRM работает локально.

Пока сервер запущен — система доступна.  
Если сервер остановлен — доступ пропадает.

Данные, файлы и чаты остаются внутри локальной инфраструктуры компании.

Не передавай пароль.  
Не публикуй рабочую ссылку в открытых каналах.  
На общем компьютере всегда нажимай `Выйти`.
